# 项目检查与推送前修复记录

日期：2026-10-28。项目：ESP32-S3 智能家居网关。

## 本次修复

1. **Base64 越界**：原先 30718–30720 字节图像在编码器报告容量不足后仍拼接 JSON，会越界写 1 字节。现按前缀、编码内容、尾部及结束符统一计算容量，给 Mbed TLS 留出结束符空间，并检查编码返回值、输入长度及空指针。编码失败时丢帧并由原上传任务归还帧。
2. **摄像头边界与失败清理**：检查驱动返回的缓冲数量、帧索引、实际映射长度及目标帧容量；同时识别 NULL 和 MAP_FAILED。部分初始化失败会回滚，按查询长度取消映射；归还驱动缓冲失败时使该帧失效。
3. **MQTT 回调空指针**：订阅确认不再解引用可能为空的 event->data；保护空事件和空错误信息。补充客户端创建及发布参数检查。
4. **Wi-Fi 配置生命周期**：事件回调改用静态配置副本，不再持有 Svc_Mqtt_Start 栈变量的地址；补充事件组分配检查和认证模式配置。
5. **其他**：传感器 JSON 改为有长度限制的 snprintf；处理 NVS 初始化的常见页耗尽/版本不匹配；修正原 CMake 中拼接错误的编译参数。
6. **仓库准备**：公开配置头使用 XX 占位；原凭据保留到被忽略的 Svc_User_Defined.local.h。排除本地配置、编译产物和历史修改前备份。补充硬件默认配置与 README，移除未使用且锁定到本机 SDK 路径的 protocol_examples_common 依赖。

完整构建使用独立目录，不覆盖原 build 或 sdkconfig。开发环境的 IDF_TOOLS_PATH 应指向工具根目录（本机为 C:/Espressif/tools），否则会错误查找约束文件。

复现干净构建，在激活 ESP-IDF 6.0.1 的终端执行：

```sh
idf.py -B verification/2026-10-28-review/build/idf-fresh -D SDKCONFIG=verification/2026-10-28-review/build/sdkconfig-fresh -D CMAKE_C_FLAGS=-DSVC_USE_PLACEHOLDERS=1 build
```

应在 sdkconfig-fresh 不存在时执行，才能验证默认配置生成。验证脚本使用本机 MSVC / SDK 路径，其他机器需对应调整。
