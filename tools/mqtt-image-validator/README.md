## 使用方法

1. 完整解压 ZIP，保持程序、DLL 和各插件文件夹在原有相对位置。
2. 打开 `图像接收端.exe`。
3. 填写与 ESP32 固件相同的 MQTT Broker 地址和端口，以及接收端自己的登录参数。
4. 为 PC 接收端设置独立的 MQTT Client ID，避免与 ESP32 发布端使用同一个 ID。
5. 连接 Broker，订阅固件 `USE_VIDEO_TOPIC_PUBLISH` 对应的视频主题。
6. 在 ESP32 上按 Key1 开始采集，查看接收端显示的图像。

原目录的 `config.ini` 和 `config_rx.ini` 是保存连接参数的二进制 Qt 配置文件，**未收入工具包**。使用时请自行填写连接信息。原程序目录和原配置文件未被修改。
